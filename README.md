# Virtual Board

Skolprojekt för kursen Webbtjänster och molnteknologi.

Projektet består av:
- Auth API
- Virtual Board API
- Frontend

Teknologier:
Node.js, Express, PostgreSQL/Neon, Prisma, JWT, bcrypt, HTML, CSS, JavaScript och Docker.

AI har använts som stöd för planering, kodförslag och felsökning.
